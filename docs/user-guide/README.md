# OFAST user guide

This guide is written for people who have never used Unreal Engine or modding tools. It grows with every milestone.

> Nothing is usable yet — OFAST is in milestone M0. See the [roadmap](../roadmap.md).

## What you will need

- Counter-Strike 2 (installed through Steam)
- Unreal Engine 5.8 (free, through the Epic Games Launcher)
- A graphics card that runs Unreal Engine 5 with Lumen comfortably
