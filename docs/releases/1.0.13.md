Demos recorded since CS2's update of November 11 can be read again. Update if you want to use a demo from November 11 or later.

**Download** `OFAST-Studio_1.0.13_x64-setup.exe` below and run it over your current version, or press **Update** in the Studio's bar (1.0.3 and later). The maps and rounds you already sent stay; nothing needs sending again.

## Demos of CS2 1.41.9.7

- CS2 1.41.9.7 (November 11) changed how demos store some of their values. OFAST 1.0.12 and earlier stop with an error on every demo recorded since that update; demos recorded before it were never affected. 1.0.13 reads both.
- 1.0.12 was announced as checked on CS2 1.41.9.7, but the check only replayed demos recorded before the update, which kept the old format. Each CS2 update is now also checked with a demo recorded on the new build.
- When a later CS2 update stores values in a way OFAST doesn't know, the export now stops with a message that says to update OFAST, instead of an error about the demo's contents.

Checked on demos recorded offline on the new build: rounds with bots, shots with six guns, and a smoke, an HE grenade and a flashbang. A matchmaking or tournament demo recorded since the update has not been tried yet: if one does not open, please report it on GitHub.

## Known issues

- Seen through the player's eyes, the gun kicks up more after each shot than in CS2.
- With the players layer, the players are lit without the light bounced from the walls around them: in a dark place they come out too dark.

Checked on CS2 1.41.9.7 (build 2000943).
