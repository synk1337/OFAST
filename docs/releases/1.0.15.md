Support for CS2 1.42.0.0: the Studio shows it green again.

**Download** `OFAST-Studio_1.0.15_x64-setup.exe` below and run it over your current version, or press **Update** in the Studio's bar (1.0.3 and later). The maps and rounds you already sent stay; nothing needs sending again.

## CS2 1.42.0.0

- CS2's update of November 21 changed its engine, the AWP's slow reload animation, a fire effect and two maps. OFAST exports and imports rounds as before: the reference round gives the same files as on 1.41.9.8, byte for byte. Only the Studio's check of your CS2 version changed: 1.0.14 and earlier flag this build as not yet checked.
- Demos of the new build: two rounds of bots recorded offline on 1.42.0.0 export without a warning. A matchmaking or tournament demo recorded since the update has not been tried yet: if one does not open, please report it on GitHub.
- Inferno, which the update touched, exports as before. A map already sent to Unreal is not sent again.

## Viewmodel panel

- The button that puts the gun's settings back is now named **Classic** (it was "CS2's default"). OFAST starts with CS2's Classic gun position (field of view 68, offsets 2.5, 0, −1.5), which is not what a new CS2 install shows (Desktop: 60 and 1, 1, −1). The settings themselves have not changed.

## Known issues

- Seen through the player's eyes, a slow reload plays twice as fast as in CS2: the gun is back at rest halfway, then stays still while the player is still reloading. In CS2 a reload started while holding the walk key takes twice as long as a normal one (seen in a tournament demo of CS2 1.41.9.5). Found while checking this update; earlier versions of OFAST have it too.
- With the players layer, the players are lit without the light bounced from the walls around them: in a dark place they come out too dark.

Checked on CS2 1.42.0.0 (build 2000948).
