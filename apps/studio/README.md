# ofast-studio (planned — M3)

The beginner-friendly desktop app: Rust + [Tauri 2](https://tauri.app/) with a web UI.

- Finds the CS2 install and builds an asset cache
- Demo browser: rounds, kills, 2D radar
- Highlight picker and shot settings
- Launches CS2 + ofast-capture for recording
- "Send to Unreal"

All file reading goes through `crates/ofast-core`.
